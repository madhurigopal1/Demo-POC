# Demo-POC

This repository contains product decks, a 2-minute combined video script and shot list, and assets to showcase eight prototype POCs derived from the user's repositories.

Included POCs (one deck per repo):
- Code-to-Visualizer
- Data-Classification-Catgeorization
- Data-to-ML-Classifier-Models
- Data-Mapping
- recommendations-retail
- Langchain-code-noAPI
- knowledge-management-flow
- NeuroAI-Product1

Structure
- /decks/<repo>.pptx  (slide text and speaker notes)
- /videos/script.txt   (combined 2-minute script and shot list)
- /videos/editing-guide.md  (cut list, timestamps, ffmpeg commands)
- /assets/placeholders/ (image filename suggestions and where to capture them)
- README.md (this file)

How to use
1. Clone the repo
2. Review each deck and replace placeholder images with screenshots from the add-llm-integrations branches in each repo.
3. Record the short screen captures as described in the script, assemble them using the editing guide, and render the final 2-minute highlight video.
