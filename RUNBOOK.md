# Demo-POC Runbook

This repository contains generated decks (slide content files and placeholders), a combined 2-minute video script, and an editing guide to assemble the final highlight reel.

How to produce the final deliverables
1. Replace placeholder images in /assets/placeholders/ with screenshots from the add-llm-integrations branch of each repo.
2. Create screen-recordings per the script timestamps and save them using the filenames described in videos/editing-guide.md.
3. Record the voiceover using the script in videos/script.txt (or speak directly while capturing screen video).
4. Use ffmpeg commands in videos/editing-guide.md to stitch clips and mix audio.
5. Commit the decks, scripts, and assets into the Demo-POC repo and push.
